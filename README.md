# React Authentication Dashboard

This project demonstrates a frontend authentication flow with protected routing and API integration. It is built to simulate real-world login behavior and secure dashboard access using mocked authentication logic.

## Features

* Mock user authentication
* Token storage using localStorage
* Protected dashboard route
* Public API data fetching
* Loading indicators using Ant Design Spin
* Notification-based feedback for user actions
* Logout functionality

## Technologies Used

* React
* React Router DOM
* Axios
* Ant Design
* CSS

## Setup Instructions

Clone the repository:

```
git clone <repository-url>
```

Install dependencies:

```
npm install
```

Run the application:

```
npm start
```

The application will be available at:

```
http://localhost:3000
```
